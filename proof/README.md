# Proof and regression evidence

The current 272-byte build accepts losing replies by starting each non-leaf
search at signed score -128. Removing the redundant `AND AH,DL` from the pawn
predicate pays for the two-byte initializer. Search depth remains four plies.

## Local Z3 obligations

`queries/pawn_and_selection.smt2` returned `UNSAT` under Z3 4.16.0. It checks:

- After `TEST AH,DH` rejects friendly pieces and borders, NEG's nonzero test
  produces the same occupancy carry as the former AND/NEG sequence, for both
  side masks and the initialized board alphabet.
- No signed byte score is less than -128, so the first generated reply passes
  the existing signed comparison and records a source and destination.

The board alphabet is preserved by moves and undo, which store zero or an
existing piece byte. Both predicates restore AX with POP and use the same
RCL/TEST/JPO continuation. The local query models the carry and comparison;
it is not an instruction decoder or a proof of recursive search correctness.

Replay from the repository root:

```sh
z3 proof/queries/pawn_and_selection.smt2
```

The query prints `unsat` followed by a native Z3 proof expression. The captured
expression is in `proofs/pawn_and_selection.proof`; statistics are in
`stats/pawn_and_selection.stats`. These are internal Z3 objects, not certificates
checked by an independent kernel. Trust includes Z3 and the stated model.

## Emulator regression

`search-regression.json` is generated by `tools/validate_search.py` with NASM
3.02 and Unicorn 2.1.4. From the repository root, run:

```sh
python3 -m pip install unicorn==2.1.4
python3 tools/validate_search.py
shasum -a 256 proof/search-regression.json
```

The harness rebuilds the current source and a straightforward 274-byte control:
the control has the same -128 initializer but retains the old pawn AND. It
checks 3,584 pawn cases, 20 opening inputs, three two-turn sequences, and 100
seeded synthetic positions. Full game-flow tests use depth 4; synthetic tests
use depth 3 to bound open-board branching. Selected moves are checked against
an independent reduced-rule generator, and speculative board changes must be
undone. Synthetic fixtures are not a claim of full FIDE position legality.

The stopping regression injects `7k/p7/8/1Q6/8/8/8/7K w - - 0 1` before
White's `b5a5`. The preserved zero-floor executable stops at runtime `0162h`;
the current build chooses `a7a6` at score -1 and reaches the next input boundary.

DOS I/O is modeled with register preservation. This does not certify real DOS
compatibility, increased playing strength, complete chess legality, unbounded
whole-program equivalence, or a globally minimal executable size. The changed
search intentionally differs from the old zero-floor behavior.
